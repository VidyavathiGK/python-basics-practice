# Python Basics Practice

This repository contains basic Python programs, object-oriented programming examples, and algorithmic scripts for practice and learning.

## Programs Included

* **Hello World:** Basic output script (`Hello_world.py`)
* **Mathematical Operations:** Factorial, sum of digits, reverse number, and largest of three numbers
* **Number Properties:** Armstrong number, Neon number, Perfect number, Prime number, and Strong number checkers
* **Utility Scripts:** Even or odd checker, palindrome validator, and a simple calculator
* **Object-Oriented Programming:** 
  * Bank account management (`bank_account.py`, `bank_management_system.py`)
  * Library book management (`library_book.py`)
  * Music playlist management (`music_playlist.py`)
  * Virtual pet simulator (`pet_simulator.py`)
  * Smart bulb simulation (`smart_bulb.py`)

## Purpose

I created this repository to improve my Python programming skills, practice object-oriented design principles, and maintain consistency in coding practice.

More programs coming soon!
